# 文档目录

所有课程文档按类型归档，代码相关的架构决策与接口说明也放在这里。

| 目录 | 用途 | 命名建议 |
|---|---|---|
| `requirements/` | 需求确认工作流、需求清单、变更记录 | `需求名称-v1.5.md` |
| `design/` | 设计文档、架构决策（ADR）、接口设计 | `模块-主题.md` |
| `diagrams/` | 架构图、流程图、时序图源文件 | `图名.drawio` / `.png` |
| `meetings/` | 会议记录、讨论纪要 | `YYYY-MM-DD-主题.md` |
| `reports/` | 阶段报告、周报、实验报告 | `YYYY-MM-DD-阶段报告.md` |

约定：

- Markdown 使用 UTF-8、LF 换行。
- 二进制文档（PDF、图片）保留原始版本，不放代码仓库的构建产物。
- 文档中的图如果被 Markdown 引用，两个文件放在同一目录，便于相对路径渲染。
